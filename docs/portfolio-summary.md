# Portfolio Summary

Rebuilt YachayBot from a hackathon chatbot into an evidence-first RAG search platform prototype using Next.js, TypeScript, FastAPI scaffolding, documented Postgres/pgvector migrations, inspectable source metadata, deterministic retrieval, source-grounded answers, citations, and retrieval evaluation metrics for Peruvian cultural and educational resources.

## Portfolio Card Copy

YachayBot v2 turns a cultural education chatbot demo into a source-grounded AI search system. Users can search public Peruvian educational and cultural resources, inspect source cards, see citations, and review retrieval eval metrics. The project emphasizes honest limitations, multilingual boundaries, and engineering visibility over broad AI claims.
