# ADR 0003: Use Search-First UI

## Status

Proposed

## Context

The original app presents a chatbot and marketing-style sections. The v2 product principle says the answer is never the only product; evidence is part of the product.

## Decision

Make search the first screen of the v2 experience.

## Consequences

- Users can inspect retrieved sources before trusting generated answers.
- The product is positioned as educational search, not a generic chatbot.
- Marketing copy becomes secondary to the working search experience.
